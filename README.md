# CodeAlpha Stock Portfolio Tracker

## About the Project
A simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

## Features
- Enter stock symbols and quantities
- Uses predefined stock prices
- Calculates individual investment value
- Calculates total portfolio investment
- Saves the result in a text file

## Technologies Used
- Python
- Dictionary
- Input/Output
- Basic Arithmetic
- File Handling

## How to Run
Run the following command:

python stock_portfolio_tracker.py

## Example
AAPL × 5 = $900
